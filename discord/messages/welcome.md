# Welcome to M3AT: Maru's 3D Animated Toons!

M3AT is a RimWorld mod that adds on to **IsoRim Waylith**, which shows your colony in 3D. M3AT replaces IsoRim's pawns with animated chibi versions: around 200 animations covering most of the game, 3D apparel for the base game, every DLC and Combat Extended, hair built from any hair mod's textures, visible injuries, holstered weapons, ragdolls and a freecam (press **F6**).

It's an **early version**. A lot already works, but you'll find rough edges, and this server is where to tell us about them.
