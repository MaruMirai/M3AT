# Welcome to M3AT: Maru's 3D Animated Toons!

M3AT is a RimWorld mod that adds on to **IsoRim**, which shows your colony in 3D. M3AT replaces IsoRim's pawns with animated chibi versions: they walk, run, sit, sleep, work, fight, eat, play music, carry each other about, limp when they're hurt and fall over when they're shot.

It's an **early version**. A lot already works, but you'll find rough edges, and this server is where to tell me about them.
