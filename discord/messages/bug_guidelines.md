To report a bug, use #submit-bug-report: see the pinned message there.

This forum is for talking about bugs in the open. One post per problem, with a short title that says what goes wrong (for example "Pawns float above beds"). The **Copy bug report** text from the M3AT mod options and a screenshot help a lot. Check the known issues in #welcome first, and add tags to your post to help sort it.
